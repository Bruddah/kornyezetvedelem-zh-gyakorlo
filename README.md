# Környezetvédelem ZH-gyakorló

Játékos gyakorló a Környezetvédelem tárgy (Bedő Anett) előadásainak ellenőrző kérdéseihez: 90 kérdés, 11 témakör, Quizlet-szerű tanuló mód és forgatós kártyák a nulláról kezdőknek, kulcsszavas pontozás, XP/szintek, ZH-próba időzítővel, minta ZH, villámkör.

**Megnyitás:** https://bruddah.github.io/kornyezetvedelem-zh-gyakorlo/

A haladás a böngészőben (localStorage) mentődik.
